# Basil Hospitality — GHG Emissions Dashboard

## Project Overview
An interactive Power BI dashboard project focused on greenhouse gas (GHG) emissions analysis for hospitality operations.

This project demonstrates how business intelligence tools can help organize sustainability data and communicate emissions-related insights.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation and transformations
- DAX for calculations and analytical measures

## Key Skills Demonstrated
- Power BI dashboard development
- Data cleaning and transformation
- Emissions data analysis
- KPI reporting and visualization
- Business-focused sustainability reporting

## Dashboard File
**File:** `basil_final_dashboard-main.pbix`

Download the file and open it in Microsoft Power BI Desktop to explore the report. Depending on the original data connections, you may need to reconnect external data sources.
